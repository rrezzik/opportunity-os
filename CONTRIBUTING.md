# Contributing

## Workflow

1. Choose one bounded issue with a clear definition of done.
2. Create a feature branch.
3. Implement only the agreed scope.
4. Add or update tests and documentation.
5. Run the repository checks.
6. Open a pull request describing the outcome, verification, privacy impact, and deferred work.

## Commit Guidance

Use concise imperative commit subjects. Conventional Commit prefixes such as `feat:`, `fix:`, `docs:`, `test:`, and `chore:` are encouraged when they improve clarity.

## Data and Fixtures

Do not contribute personal career data or full captured job pages. Use synthetic or carefully minimized examples that preserve the behavior being tested without exposing private or unnecessarily copied content.

## Scope

Opportunity OS values small working slices. Avoid speculative abstractions, autonomous external actions, or infrastructure without a demonstrated requirement.
